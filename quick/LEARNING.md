# Quick Lab — 学習データとUX仕様

## 何を覚えるか
- 速成は倉頡の先頭・末尾の字根コードを使う。**1キーで入力する基本字根もある**。
- 倉頡で「女（V）」と呼ぶキーには補助字形も属する。漢字「女」が見える必要はない。
- 例：**晨**＝倉頡 **AMMV** → 速成 **AV**。「日」はAで「辰」の末尾はV。
- 文字の部首・漢字の意味・字根の符号は同じものではない。

## 第5代を基準にした問題データ
- `data.js`：初期54漢字、10文字は1キー。各文字に倉頡原碼・速成碼・日本語の意味・可視化用の字形説明・典拠URLを保存。
- 原典：Rime `cangjie5.base.dict.yaml`。速成は倉頡碼の首尾を利用（Rime Quickの実装）。
- 出典のコード表には複数候補を持つ漢字がある。現教材ではそのうちの1コードを採用している。
- 第3代と第5代では一部コードが異なるため、Windows等のIMEと一致しないケースがあり得る。最終的なOS一致検証は未実施。
- 分解画面で「字形のヒント」と記した箇所は説明用の簡略表現。すべての筆画を厳密に切り出した画像ではない。

## UX
- 1回10問。初学者を優先し、間違えた問題を適宜再出題。
- スマホは画面内の字根キーボード、PCは物理キーボードに対応。
- 回答後、最初/最後の字根・コード・解説をインライン表示。
- 先頭・末尾のどちらを間違えたか個別にカウント。
- 正解の連続回数に応じて翌日・3日後・7日後・14日後・30日後に復習予定を設定。誤答とヒント使用時は当日復習。
- `localStorage` に学習履歴保存。データはサーバーへ送信しない。

## テスト
- `node quick/test-data.js`：54文字のコードの整合性、重複、解説、画面のJS構文と基本操作を検査。
- GitHub Actions `quick-lab-check.yml` で自動実行する。
- **未実施**：iPhoneの実機テスト、実際のIMEを使った候補選択テスト、字根の筆画アニメーション。

## 携帯ゲーム機型UX（Phase 4A–4C）
- 画面の高さを固定し、問題表示と回答解説を同じ液晶領域で切り替える。
- 回答後は「字根／ことば」タブを表示。熟語も液晶内部のみスクロール。
- 解答・復習・保存データは変更せず、`quick-lab-v1` を維持。
- 発音は端末の香港広東語音声がある場合のみ再生する。
- 実機の小画面・VoiceOver確認は別途必要。

## 問題拡張 第1回（100字）
- 既存54字を「入門54字」、新規46字を含む全100字を「基本100字」として選択可能。
- 46字の倉頡コードは Rime `cangjie5.base.dict.yaml` の単字行を照合し、速成コードは首尾の字母から導出。

## 頻出語拡充 第2回（319字・2026-11-24）
- 既存304字に、**一・該・即・就・喇・嗰・乜・使・如・未・解・太・幫・意・思**の15字を追加。全319字。
- 15字の倉頡第5代コードをRime `cangjie5.base.dict.yaml` の単字行と照合。速成コードは原碼の首尾（1文字の原碼はその1文字）を使用。
- **一はMの1キー**。**乜は原辞書に複数の原碼（PN・PS・XPN）があり、現教材ではPNを代表コードとして採用**。別の候補で入力しても現クイズでは正解扱いしないため、将来は異コードの許容を検討する。
- 香港日常コースに15字を追加し、旧コースの「入門54・基本100・日常150・生活200・字根比較250」は範囲を変更していない。
- 関連語32件を新規字に紐付け、そのうち26種類は既存ライブラリにない新しい表現。単字の関連語は重複込みで管理されるため、ユニーク語句数は523→549。
- `phrases.html` に「唔該」「唔好意思」「即係」「點解」「幫我」「唔使」「乜嘢」「嗰個」「如果」「一啲」を追加。入力可能なフレーズは5→15件。
- 150語句の監査用候補リストに対し、全構成文字を入力できる語句は81→102（54%→68%）。**これは入力用文字の対応率であり、会話の理解率ではない**。
- `node quick/test-data.js` を現在のデータと分離テスト群に対応するCI入口へ更新し、Node.js 22の標準ライブラリのみで回帰テストを実行できる設計とした。
- 新語句の用法・読み・日本語訳は公開ソースによる初期確認。全例について広東語母語話者の校閲が完了したものではない。古いコーパスの「上位15語」という意味ではなく、頻度と実用性から選んだ優先15字。

## 頻出語拡充 第3回（実用55表現・2026-11-24）

### 今回の追加
- 単字教材は**319字のまま**。構成文字がすべて入力可能な語句を40件追加し、フレーズ入力を**15→55件**に拡充。
- 40件のうち32件は既存 `extras.js` の関連語から採用、8件は実用性を基準に新規整理。**「統計的な頻度上位40語」ではない**。
- 新規整理8件：可唔可以・慢啲講・我想要・唔知道・唔明・唔得・我唔知・幾錢。辞典・文脈資料を参照しつつ、**母語話者による全件の校閲は未実施**。語彙データに `reviewStatus: "initial-draft"` として区別。
- 残る既存15件は意味・メモ・文字列を引き継ぎ、直接リンク `phrases.html?phrase=...` も維持。

### データ設計とUX
- `lexicon/core.js` を単一の正本（55件）とし、各語句に ID・表記・粤拼・日本語訳・分類・メモ・出典／由来・校閲ステータスを記録。
- `lexicon/search.js` は副作用のない検索処理。漢字・日本語・粤拼（声調数字あり／なし）と7つの場面フィルターに対応。
- `phrases.html` は旧ソース内の15件の配列を除去し、共通辞書を読み込む。検索・絞り込み中に練習中の語句を勝手に切り替えず、選択操作でのみ変更。
- フレーズ全体の広東語音声を `speech.js` と連携。自動再生なし。香港広東語の音声はOS／ブラウザに依存し、利用できない場合には注意を表示。
- `phrase-vocab.css` で単字画面のネオン系デザインと統一し、44px以上の操作領域、画面幅390px以下、Reduced Motion・高コントラストに対応。
- 入力時の安全策：検索欄やセレクトにフォーカスしたまま押したキーを、速成入力として解釈しない。
- 今回は既存 `extras.js` と `data.js` の内容、および `quick-lab-v1` の学習履歴形式を変更しない。

## 頻出語拡充 第5回（実用105表現・2026-11-25）

### 最新仕様と目的
- 単字教材371字、フレーズ練習105件。既存55件を先頭に維持し、語句ID `hk-001`〜`hk-055`・読み・表記を変更しない。
- 150候補を香港向けの表記で整理した149語句について、単字の入力に必要な文字は149/149揃う。しかし前回のフレーズ練習で選べたのは33語句のみ。今回は**既存の関連語データに読みと意味がある50語句**を新たに接続し、83/149語句が独立したフレーズ練習で選択可能になった。
- この「83/149」は**固定監査候補のうちフレーズ教材に登録済みの比率**。香港の発話コーパス全体に対する語彙カバレッジ率ではない。
- 実装例：等陣 / 講多次 / 冇問題 / 太貴 / 平啲 / 食咗飯未 / 廁所 / 醫院 / 救命。50件すべて2文字以上で、構成字が既存371字に収録済み。
- 50件の `origin` は `existing-extra-audited`、`source` は `quick/extras.js`、`reviewStatus` は `from-existing-dictionary-not-native-reviewed`。母語話者によるすべての用法・声調の最終校閲は未実施。

### UX・技術
- `lexicon/core.js` が105件の単一の正本。検索・フレーズ入力は同じ表記・粤拼を参照し、学習進捗（`quick-lab-v1`）を変更しない。
- 従来の漢字・日本語・粤拼検索（声調数字あり/なし）と発音再生、`?phrase=...` の直接リンクを維持。
- `lexicon/search.js` に8番目の分類「困ったとき・体調（`help`）」を追加。廁所 / 唔舒服 / 醫院 / 救命 の4件を収録。
- 分類選択欄には各カテゴリの収録件数を表示。大量追加時に「どの場面に何があるか」を見つけやすくした。
- メイン画面の入口表示を105件へ更新。検索画面の初期件数を動的に計算し、辞書をさらに拡張しても固定件数チェックで画面が停止しない設計へ。
- `index.html` の字根解剖室では、新規追加字の字形筆画が未校閲の場合に、**字首・字末のコード位置と辞典の図への参照**を表示。根拠のない筆画オーバーレイは生成しない。
- 字根の位置数を固定値で検証していた回帰テストは、教材の収録状況に応じて動的に計算する方式へ変更。

### 品質ゲート
